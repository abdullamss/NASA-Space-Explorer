# Reflection
Through this lab, I learned how GitHub can be used not only to store code but also to manage and organize a software project. I learned how to create a repository, use issues to organize tasks, create branches, make commits, and use pull requests to merge changes into the main branch.
One of the most useful things I learned was how branches allow developers to work on different features without directly changing the main version of the project. I also found GitHub Issues useful because they make it easier to divide a project into smaller tasks and keep track of the work that needs to be completed.
The most challenging part for me was understanding the relationship between branches, commits, and pull requests. However, after using them in the project, the process became clearer and more interesting.
If I had more time, I would improve the design of the NASA Space Explorer website and add more planets, NASA missions, images, and interactive features.
