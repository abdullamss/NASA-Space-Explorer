# NASA Space Explorer

## Project Idea

NASA Space Explorer is a simple educational website designed to help users learn more about space, planets, and NASA missions. The project presents space information in a simple and easy-to-understand format.

## How It Helps NASA and Space Education

The project helps promote interest in space exploration by making basic information about planets and NASA missions easy to access and understand.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Explore the planets and space information displayed on the website.
